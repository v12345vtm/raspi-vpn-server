# 🏡 Raspberry Pi 4 Thuis-VPN (WireGuard)

Met dit script installeer je eenvoudig een WireGuard VPN-server op je Raspberry Pi. Hiermee kun je vanuit het buitenland (bijv. Spanje) veilig verbinden met je thuisnetwerk, alsof je gewoon thuis op de bank zit.

## 🚀 Installatie Instructies

Log in op je Raspberry Pi via SSH en voer het volgende commando uit om het script te downloaden en direct te starten:

# 1. Download het script direct van jouw GitHub (via de 'raw' link)
wget -O setup_vpn.sh https://raw.githubusercontent.com/v12345vtm/raspi-vpn-server/main/setup_vpn.sh

# 2. Maak het script uitvoerbaar
chmod +x setup_vpn.sh

# 3. Voer het script uit
./setup_vpn.sh
